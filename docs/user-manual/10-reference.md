## 10.30 ファイル / フォルダ場所

```
%LocalAppData%\ViewGrid\
├─ active.json              アクティブワークスペース名
├─ workspaces.json          ワークスペース一覧
├─ settings.json            アプリ全体設定 (テーマ / 言語 / 既定値)
├─ workspaces\
│   ├─ <name>\
│   │   ├─ viewgrid.db          SQLite DB
│   │   ├─ images\<hash[0..1]>\<hash>.{ext}   画像本体
│   │   └─ thumbnails\<hash[0..1]>\<hash>.webp  サムネ
│   └─ .trash\<name>-<timestamp>\   削除済みワークスペース
└─ logs\viewgrid-*.log      Serilog ログ (UTF-8)
```

実体パスは Windows 11 の場合 `C:\Users\<user>\AppData\Local\ViewGrid\`。 エクスプローラのアドレスバーに `%LocalAppData%\ViewGrid` と入力すると直接開けます。

## 10.31 トラブルシューティング

### 10.31.1 二重起動でロックダイアログが出る

同じワークスペースを別プロセスで開こうとした場合の保護。 既存プロセスをアクティブにして編集を続けてください。 既存プロセスが残骸の場合 (クラッシュ後等) はタスクマネージャで終了させてから再起動。

### 10.31.2 サムネが壊れる / 不整合

ファイル取り込み中にプロセスが落ちた場合などに発生。 **設定 → サムネ一括再生成** で全アセットを再生成できます。 完了後はアプリ再起動を推奨。

### 10.31.3 .trash/ にゴミが溜まる

削除したワークスペースは自動削除されません。 不要なら `%LocalAppData%\ViewGrid\workspaces\.trash\` を手動で削除してください。

### 10.31.4 設定ダイアログで言語を変えても一部が日本語のまま

候補リスト ItemVM の文言 (バリアント表示名等) は **次回ロードで反映** されます。 ワークスペース切替 / 配置タブ再表示 / アプリ再起動のいずれかで即時更新されます。

### 10.31.5 編集が消えた / 戻った

配置 Inspector の編集は **保存ボタン** を押すまで永続化されません。 ステータスバーに **● 未保存の変更** バッジが出ている状態でアプリを閉じる / グリッド切替を行うと、 通常は自動 flush されますが、 まれに失敗する場合があります (要再起動)。 設定で自動保存を ON にすると軽減できます (実験的)。

### 10.31.6 ログを確認したい

`%LocalAppData%\ViewGrid\logs\viewgrid-<日付>.log` を任意のテキストエディタで開く (UTF-8)。 Windows コンソール (cp932) では化けます。

## 10.32 用語集

| 用語 | 説明 |
|---|---|
| **ワークスペース** | DB / 画像 / サムネを物理的に分離した単位 (`%LocalAppData%\ViewGrid\workspaces\<name>\`) |
| **アセット** | 取り込んだ画像ファイル (1 ファイル = 1 アセット) |
| **バリアント** (論理コピー) | アセットから派生する設定違いの使い回し単位。 共有特性 (回転 / トリミング等) を持つ |
| **配置** | バリアントをグリッドの特定セルに置いた実体。 配置固有特性 (占有セル / ピクセル微調整) を持つ |
| **グリッド** | NxM の出力キャンバス。 列・行の比率、 キャンバス px サイズを持つ |
| **共有特性** | バリアント単位の特性。 同バリアントを参照する全配置に反映 |
| **配置固有特性** | 配置単位の特性。 同バリアントの別配置には影響しない |
| **占有セル** | 配置が占有するセル数 (W×H)。 既定 1×1 |
| **ピクセル微調整** (PixelOffset) | セル境界からの ΔX / ΔY (px)。 配置位置の細かい調整 |
| **スケーリング** | セルと画像の縦横比が違うときの挙動 (6 モード) |
| **アライメント** | セル内の画像配置位置 / 表示部分の選択 (9 アンカー) |
| **AutoCrop** | 指定色の外周余白を自動検出して切り抜く機能 |
| **ManualCrop** | 任意のピクセル矩形を指定するトリミング |
| **保護領域** (ProtectedRegion) | セル内の画像の一部を独立アセットとして 「浮かせる」 機能 |
| **PhotoBoard** | フレーム + 影 + ジッターで写真ボード風に出力するモード |
| **TrimMode** | 出力 PNG の切り出し範囲指定 (全面 / 占有セル / 描画ピクセル) |
| **履歴 Flyout** | ステータスバー右の操作履歴一覧。 過去位置への一括ジャンプ可 |
| **Fork (バリアント分岐)** | 配置単位で既存バリアントを複製した独立バリアントに切替える操作 |
