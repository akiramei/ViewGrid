## 6.16 PhotoBoard 詳細

写真ボード風モードで使うパラメータ。

### 6.16.1 PhotoBoard とは

通常モードがセル境界を厳密に守った 「タイル状」 出力であるのに対し、 PhotoBoard モードは各配置を **独立した写真** として扱い、 フレーム / 影 / ジッターを加えた合成画像を出力します。 結果は 「机に並べた写真の俯瞰」 のような見た目になります。

通常モードと PhotoBoard モードは出力時の **描画パイプラインだけ** が異なり、 グリッドや配置のデータは共有されます。 セッション中にいつでも切替可能 (永続化されない)。

### 6.16.2 スタイルプリセット

3 種類のスタイル (Natural / Rough / Scattered) が用意されています。 各スタイルは
**回転量・位置ジッター・重なり頻度・拡張・ドリフト**の組合せをチューニングしてあり、 同じ強度でも
スタイルごとに 「散らかし具合」 がハッキリ変わります。 フレーム (オフホワイトのポラロイド枠) と
ドロップシャドウはスタイル間で共通です (色や枠種の選択肢はありません)。

| スタイル | 雰囲気 |
|---|---|
| **Natural (ナチュラル)** | 軽い揺らぎ + 重なりなし。 整然とした 「写真アルバム」 風 |
| **Rough (ラフ)** | 中程度の回転 + たまの重なり。 「ノートに貼った写真」 風 |
| **Scattered (バラ撒き)** | 大胆な回転 + 頻繁な重なり + 大きめの拡張。 「机にぶちまけた写真」 風 |

### 6.16.3 強度スライダー (Intensity)

選んだスタイルの 「人間っぽさ」 = 二段階カーブの強度を控えめ ↔ 大胆で調整。 既定 0.5 で 「そのスタイルのベースライン」。

- 0.0 寄り (控えめ): ジッターや傾きを抑えて整然と
- 0.5 (既定): スタイル本来の趣
- 1.0 寄り (大胆): ジッターと傾きをさらに強調して 「机に投げ出した」 感

**既定に戻す** ボタンでスライダーを 0.5 にリセット。 スタイル切替時も 0.5 に自動リセットされます (= スタイルごとに別の基準点でスライドする想定)。

### 6.16.4 計算コストとプレビュー

PhotoBoard の最終合成は **約 1 秒** かかります。 そのため、 強度スライダーをドラッグしながらの **リアルタイム調整は推奨されません**。

推奨ワークフロー:
1. 右ペインで設定を変更
2. **プレビュー** ボタンを押して結果を確認
3. 気に入らなければ右ペイン側で再調整 → 再プレビュー

## 6.17 切り出し (Trim Mode)

通常モード / PhotoBoard モードどちらでも適用される最終的な切り出し範囲指定。

| モード | 切り出し範囲 |
|---|---|
| **全面** | キャンバス全体 (キャンバス幅 × 高さ) |
| **占有セル** | 配置が占有しているセル群の bbox |
| **描画ピクセル** | 描画されたピクセルを走査して求めた bbox (完全 / ほぼ透明なフチは無視) |

「全面」 は出力サイズが固定、 「占有セル」 は配置範囲のみ、 「描画ピクセル」 は実際に描かれた範囲のみ。 PhotoBoard では影 / ジッターの結果も含めて bbox 計算されます。

### 6.17.1 モードの使い分け

| 状況 | 推奨モード |
|---|---|
| **常に同じサイズの PNG が欲しい** (SNS 投稿の規格揃え等) | 全面 |
| **空きセルを含めず必要な配置だけ出したい** | 占有セル |
| **PhotoBoard で写真の傾き分も含めてピッタリ切り出したい** | 描画ピクセル |
| **透明背景のキャンバスでアイコン素材として出力したい** | 描画ピクセル (余白なし) |

### 6.17.2 各モードの具体例

3×3 グリッド (キャンバス 1200×1200) で、 左上 2×2 セルに 1 件、 右下 1×1 セルに 1 件配置している場合:

| モード | 出力 PNG のサイズ | 内容 |
|---|---|---|
| 全面 | 1200×1200 | キャンバス全体 (中央セル + 右上 + 左下は空きで透過。 背景色オプションは無い) |
| 占有セル | 約 1200×1200 | 左上配置の bbox と右下配置の bbox を統合した範囲 (この例だと全面とほぼ同じ) |
| 描画ピクセル | 約 1000×1000 | 描画されたピクセルのみ (完全 / ほぼ透明なフチは無視)。 配置の Scaling 結果として透過部分があればそこは省かれる |

PhotoBoard モードでは、 ジッター (傾き) や影が出るぶん bbox が広がります。 「描画ピクセル」 で切ると 「写真の角がちょうど入る」 サイズになります。

### 6.17.3 注意点

- 「占有セル」 / 「描画ピクセル」 では出力サイズが配置によって変動するので、 サイズを揃えたいときは 「全面」 を使う
- 「描画ピクセル」 は描画されたピクセルを走査します。 完全に透明 / ほぼ透明なフチ (アンチエイリアスの極薄フチなど) は無視されますが、 一定以上の半透明部分は含まれます。 結果サイズが期待より大きい場合はキャンバス全体に半透明部分が散らばっていないか確認

### 6.18.1 ズーム操作

- **Fit**: ウィンドウに収めるサイズ
- **100%**: 物理ピクセル等倍 (出力 PNG と同じサイズ)
- **+ / -**: 段階拡大 / 縮小 (Ctrl + ホイールでも可)
- アンカー保持ズーム (マウス位置を中心に拡大縮小)

### 6.18.2 再生成

プレビューはキャッシュされます。 配置や設定を変えた直後は自動再生成されます (約 0.5〜1 秒)。

## 6.19 PNG エクスポート

### 6.19.1 操作

- ヘッダの **Export PNG** ボタン
- メニュー **ファイル → 出力**
- `Ctrl + E`

OS ネイティブの保存ダイアログが開き、 ファイル名を指定。

### 6.19.2 出力仕様

- 形式: PNG (lossless)
- カラー: RGBA (FillMode.Transparent 等で透過があれば α 保持)
- 解像度: TrimMode に基づく実寸
- 余白: 「占有セル」 「描画ピクセル」 モードでは bbox の外側余白なし
