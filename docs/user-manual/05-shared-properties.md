# §5 共有特性

バリアント (論理コピー) に紐づき、 同じバリアントを参照する **全配置** に影響する特性を解説します。 編集箇所は 2 つあります:

- **右ペイン 「特性編集」 タブ** (候補リストからバリアント単体を選んだとき)
- **配置 Inspector の 「共有特性」 Expander** (配置選択中、 そのバリアントの共有特性を編集)

どちらから編集しても結果は同じ (同一バリアントへの書き込み)。

## 適用順序 (重要)

共有特性は次の順で画像に適用されます。 後に行く変換ほど 「上にかぶる」 イメージです。

```
元画像
  ↓ ① トリミング (AutoCrop / ManualCrop)        — 画像の有効領域を決定
  ↓ ② 回転 / 反転                                — 有効領域を回す / 反転
  ↓ ③ スケーリング + アライメント                — セル枠に収める / 覆う
  ↓ ④ 保護領域の描画 (region)                    — セル内に独立レイヤーで重ね描き
  → 完成 (キャンバス上の描画)
```

例えば 「画像を 90° 回転してから AutoCrop したい」 という指定は **できません** (順序が逆)。 代わりに ManualCrop で回転後の矩形を直接指定する、 等の代替手段になります。

## 5.11 スケーリングとアライメント

### 5.11.1 スケーリングモード

セル枠と画像の縦横比が異なるときの挙動を決めます。 ComboBox から選択。

| モード | 挙動 | 典型ユースケース |
|---|---|---|
| **原寸固定** | 元のピクセルサイズで配置。 はみ出しはセル境界でクリップ | 印刷向け原寸保持 |
| **アスペクト維持 (収める)** | アスペクト比保持でセル内に **収まる** サイズへ | 一般的な縮小フィット |
| **縮小のみ** | セルより大きいときだけ縮小、 小さいときは原寸 | 原寸を超えて拡大したくない |
| **拡大のみ** | セルより小さいときだけ拡大、 大きいときは原寸 | 小さい画像だけ揃えて拡大 |
| **アスペクト維持 (覆う・切り取り)** | アスペクト比保持でセル全体を **覆う** サイズへ。 はみ出し分はクリップ | サムネ風カバー画像 |
| **完全充填 (縦横独立)** | 縦横を独立に伸縮させてセルに完全フィット (アスペクト崩れる) | アスペクト無視で枠にフィット |

#### モード選択の指針

判断軸は 2 つだけです: **(a) アスペクト比を維持するか / (b) セル全体を埋めるか**。

|  | セルに収める (はみ出さない) | セル全体を覆う (はみ出す) |
|---|---|---|
| **アスペクト比 維持** | アスペクト維持 (収める) | アスペクト維持 (覆う・切り取り) |
| **アスペクト比 無視** | (なし、 原寸固定が近い) | 完全充填 (縦横独立) |

- **印刷物 / 入稿用** → 「原寸固定」 で実寸を保つ
- **SNS の比較画像 / ブログサムネ** → 「アスペクト維持 (覆う・切り取り)」 でセル全体を埋める
- **資料 (アスペクト保ちつつ枠に収まれば OK)** → 「アスペクト維持 (収める)」

#### モードと PixelOffset / アライメントの関係

「アスペクト維持 (収める)」 では画像がセル内に収まり、 余白が出ます。 余白の位置は **アライメント** で決まります。 アライメントを使い切ってもなお微調整したい場合は、 配置単位の **ピクセル微調整 (PixelOffset)** を併用してください。

→ §4.10.2 [ピクセル微調整](04-placements.md)

### 5.11.2 アライメント

セル中で画像をどの位置に置くかを指定する 9 アンカー (左上 / 上 / 右上 / 左 / 中央 / 右 / 左下 / 下 / 右下)。

アライメントは **画像とセルのサイズ関係で意味が変わる** 一つの設定で 2 役を担います (CSS の `background-position` と同じ流儀):

| 状況 | アライメントが決めるもの | 例 |
|---|---|---|
| **画像 ≤ セル** | 余白の付き方 = 画像の配置位置 | 「左上」 → 画像を左上に寄せて右と下に余白 |
| **画像 > セル** | クリップで残す側 = 表示部分の選択 | 「左上」 → 画像の左上部分を残して右と下を切る |

**完全充填 (Stretch)** ではアスペクト崩れ前提なので Alignment は効きません。

#### 典型的な組み合わせ

- 商品写真をきれいに中央配置 → 「アスペクト維持 (収める)」 + 「中央」
- 風景写真をサムネカバーで上半分残す → 「アスペクト維持 (覆う・切り取り)」 + 「上」
- 人物の顔が右側に寄っている → 「アスペクト維持 (覆う・切り取り)」 + 「右」 でクロップ位置調整

## 5.12 回転 / 反転

### 5.12.1 回転 (Rotation)

ComboBox から 0°/90°/180°/270° の 4 段階 (時計回り)。 任意角度は非対応です。

回転はトリミング後の画像に適用され、 スケーリング前に行われます (適用順序の §冒頭の図参照)。 つまり 90° / 270° では **画像の縦横が入れ替わり**、 セルへのフィット計算もその縦横で行われます。

### 5.12.2 反転 (Flip)

- **水平 (H)**: 左右反転
- **垂直 (V)**: 上下反転

H と V を両方 ON にすると 180° 回転と同じ結果になります。

#### 反転 → 回転の順序

内部的には **反転 → 回転** の順に適用します。 「Flip H + 90°」 と 「90° + Flip H」 は結果が異なるので注意してください。 UI 上ではこの順序を意識する必要はありません (Flip と Rotation を独立に指定するだけ)。

### 5.12.3 保護領域の独立変換

保護領域 (region) には **region 単独** の回転 / 反転があり、 親 placement の回転 / 反転とは独立に適用されます。 「写真を 90° 回転した出力でも、 セリフ領域だけ水平のまま」 といったケースに対応します。

→ §5.14.4 [独立 Rotation / Flip](#5144-独立-rotation--flip)

## 5.13 トリミング

トリミング方式は 3 つから選択 (右ペイン 「特性編集」 → 「トリミング」 タブ)。

| 方式 | 説明 |
|---|---|
| **OFF** | トリミングなし |
| **自動（単色余白）** | 指定色の外周余白を自動検出して切り抜く (AutoCrop) |
| **手動（任意矩形）** | 任意のピクセル矩形を指定 (ManualCrop) |

#### 使い分けの目安

| 状況 | 推奨 |
|---|---|
| スキャン画像 / スクリーンショットの白枠余白を一気に消したい | **自動（単色余白）** + 白 #FFFFFF |
| 透過 PNG の余白を切りたい | **自動** + 透明 (α=0) |
| 雰囲気で 「ここからここまで」 を矩形指定したい | **手動（任意矩形）** |
| 同じバリアントで 2 種類のクロップを使い分けたい | バリアントを分岐 (Fork) して別々に **手動** 指定 |

「自動」 で意図と異なるクロップになる場合は、 **許容色差** を上げるか **手動** に切り替えてください。

両方を併用することはできません (排他選択)。 自動で 9 割合った状態から微調整したい場合は、 自動で確定した矩形を見て手動でやり直す形になります。

### 5.13.1 AutoCrop (自動)

#### 対象色

ComboBox から **白 #FFFFFF** / **黒 #000000** / **透明 (α=0)** / **カスタム** を選択。 カスタム時は HEX 入力 + サムネ画像をクリックして色採取 (eyedropper)。

#### 許容色差 (Threshold)

0〜128 で指定。 0 で完全一致のみ余白扱い (既定)。 大きいほど許容範囲が広がる。

判定は **Chebyshev 距離** (R / G / B 各チャネル差の最大値) で行います:

| Threshold | 意味 |
|---|---|
| **0** | 完全一致のみ余白扱い (RGB すべて完全一致) |
| **8** | 軽微な JPEG ノイズを許容する程度 |
| **16〜32** | スキャン画像の薄い色ムラを許容 |
| **64〜** | 微妙なグラデーション余白も拾う (拾いすぎ注意) |

調整時はプレビューサムネに表示される **検出矩形 (点線)** で結果を確認しながら値を上げ下げしてください。 一気に大きくすると、 被写体側のピクセルまで余白判定して被写体が削れます。

### 5.13.2 ManualCrop (手動)

#### サムネ上の操作

右ペインのサムネ上でドラッグして矩形を描画。 8 ハンドル (4 隅 + 4 辺) でリサイズ、 内部ドラッグで移動。

#### 詳細編集ダイアログ

**詳細編集 (拡大表示)** ボタンで `ManualCropEditorWindow` が開きます。

- 拡大表示で精密編集
- ピクセル単位の数値入力 (X / Y / W / H)
- 中ボタンドラッグ または `Space` + 左ドラッグでパン
- `Ctrl + ホイール` で 6.25%〜1600% ズーム
- `矢印キー` で 1px 移動、 `Shift + 矢印` で 10px

## 5.14 保護領域 (ProtectedRegion)

セル内の画像の一部を独立したアセットとして 「浮かせる」 機能。 親の回転 / 反転 / アライメントは region に適用されず、 **スケールのみ追従** します。 通常モード / PhotoBoard モード両方で有効。

### 5.14.1 概念

```
親画像のクロップ後
└─ 保護領域 = 親画像の一部を別レイヤーとして描画
   ├─ Offset (cell 内 px 単位)
   ├─ 独立回転 / 反転 (region 単独)
   ├─ FillMode (親側の塗り)
   └─ Crop (region 内の領域指定)
```

「セリフを水平に保つ」 「ロゴ部分だけ別位置に動かす」 「特定の顔だけ強調」 等のユースケース。

### 5.14.2 保護領域の追加

特性編集 → 「保護領域」 タブ → **追加** ボタン。 サムネ画像中央に既定矩形が作成されます。

### 5.14.3 Offset (cell 内 px)

X / Y を整数 px で指定。 セル境界からの位置をずらす。

操作:
- 数値入力
- canvas 上で **オレンジ枠** (RegionSelectionFrame) を `Shift` + ドラッグ
- `Ctrl + 矢印` (1px) / `Ctrl + Shift + 矢印` (10px)

### 5.14.4 独立 Rotation / Flip

region 自身に 90°刻みの回転と水平 / 垂直反転を持たせる (親 placement とは独立)。

### 5.14.5 FillMode (親側の塗り)

region を 「持ち上げた」 後、 親画像側の元位置をどう塗るか。

| FillMode | 挙動 |
|---|---|
| **白 #FFFFFF** | 白で塗りつぶし |
| **黒 #000000** | 黒で塗りつぶし |
| **透明 (α=0)** | アルファ 0 で抜く |
| **カスタム** | HEX 指定の任意色 (eyedropper でサムネから採取可) |
| **そのまま (親画像を残す)** | 塗らない (親画像が透けて見える) |

### 5.14.6 並べ替え

複数 region は配列順 (= 描画順) で重ね描き。 リストの **↑** / **↓** ボタンで順序変更。

### 5.14.7 未選択 region の同時表示

選択していない region も canvas 上にグレーの細枠 + Opacity 0.7 で表示されます (位置確認用)。 選択中のみ操作可能。

### 5.14.8 保護領域の適用順序 (詳細)

region は **配置 → スケーリング後** にセル内へ重ね描きされます。 各 region に対する処理は以下:

```
親画像のスケーリング後の描画 (キャンバス上の矩形)
  │
  ├─ 親側塗り: FillMode に応じて region の Crop 矩形領域を塗りつぶし
  │            (親画像の元位置を 「隠す」)
  │
  └─ region 描画:
     ① region.Crop で source 画像の対応領域を切り出し
     ② region 単独の Flip → Rotation を適用 (axis 入れ替えに注意)
     ③ source → cell スケールで縮尺を合わせる (親の Scaling と独立に)
     ④ region.Offset (cell 内 px) で位置決め、 セル境界でクリップ
     ⑤ キャンバスに重ね描き
```

ポイント:
- region は **親の Scaling / Alignment / Rotation の影響を受けません** (region 単独の変換のみ)
- ただし **親と同じスケール係数** で縮尺が決まります (= 親画像の縮尺と region の縮尺は一致)
- 親画像と region の **クロップが交差しない場合は region 描画なし** ("見えている範囲に入っているものだけ出る" 直感)

### 5.14.9 操作のコツ

- **新規 region の初期位置**: 親側塗りの位置と一致する位置に既定配置されます。 そのまま FillMode を Transparent にすれば 「親画像から region 部分を切り抜いた」 結果に
- **canvas 上でドラッグ**: region の **オレンジ枠** が選択中の region を表します。 `Shift + ドラッグ` で Offset を変更
- **eyedropper**: 親画像のサムネ上をクリックすると、 その位置の色を採取して FillMode を Custom に自動切替
