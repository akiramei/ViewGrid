# ViewGrid ユーザーマニュアル

ViewGrid の全機能を体系的に解説するリファレンスマニュアルです。 まず動かしてみたい場合は [クイックスタート](../quickstart.md) を参照してください。

## 構成

本マニュアルは機能カテゴリごとに 10 章 + リファレンス章に分かれています。 各章は独立して読めますが、 用語は **§1 基本概念** で導入したものを共通利用します。

| 章 | タイトル | 内容 |
|---|---|---|
| [§1](01-concepts.md) | 基本概念 | データモデル / 画面構成 / データの保存場所 |
| [§2](02-assets.md) | アセット管理 | 画像の取り込み、 バリアント (論理コピー) |
| [§3](03-grids.md) | グリッド | 作成 / リネーム / 削除、 列・行の比率調整とロック |
| [§4](04-placements.md) | 配置 (Placement) | D&D 配置 / 移動 / 入れ替え、 配置固有特性 (Inspector) |
| [§5](05-shared-properties.md) | 共有特性 | スケーリング / 回転反転 / トリミング / 保護領域 |
| [§6](06-output.md) | 出力 | Normal / PhotoBoard、 切り出しモード、 プレビュー、 PNG エクスポート |
| [§7](07-workspaces.md) | ワークスペース | 複数ワークスペースの切替 / インポート・エクスポート |
| [§8](08-history.md) | 操作履歴 | Undo / Redo、 履歴 Flyout からの一括ジャンプ |
| [§9](09-settings.md) | 設定 | テーマ / 言語 / 既定値 / 自動保存 / 設定の入出力 |
| [§10](10-reference.md) | リファレンス | キーボードショートカット / メニュー / ファイル場所 / トラブルシューティング / 用語集 |

## 規約

- **メニュー操作**: 「**ファイル → 画像を追加...**」 のように **太字 → 太字** で表記
- **ボタン名 / UI ラベル**: 「**保存**」 のように太字
- **キーボードショートカット**: `Ctrl+Z` のようにコードフォント
- **コード / パス / 識別子**: `%LocalAppData%\ViewGrid\` のようにコードフォント
- **画面用語**: 「グリッド」 「バリアント」 「配置」 「保護領域」 等は [§10.30 用語集](10-reference.md) を参照

## 想定読者

- ViewGrid の標準ワークフローを一通り把握したい方
- 特定の機能 (PhotoBoard / 保護領域 / ワークスペース等) の挙動を詳しく知りたい方
- キーボードショートカットや設定値を確認したい方

クイックスタートで触れた内容と重複する箇所もありますが、 マニュアル側ではより詳細な挙動や、 周辺機能との関係を解説しています。
