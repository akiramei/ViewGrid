# ViewGrid User Manual

This reference manual systematically explains every feature of ViewGrid. If you just want to get started right away, see the [Quick Start](../quickstart.md).

![ViewGrid main window (three-pane layout)](../images/um/um-01-03-main-window-3pane.png)

Screenshots for each chapter appear in the body text from [§1](01-concepts.md) onward (this page is the table of contents).

## Structure

This manual is divided into 10 chapters plus a reference chapter, organized by feature category. Each chapter can be read independently, but they share the terminology introduced in **§1 Core Concepts**.

| Chapter | Title | Contents |
|---|---|---|
| [§1](01-concepts.md) | Core Concepts | Data model / screen layout / where data is stored |
| [§2](02-assets.md) | Asset Management | Importing images, variants (logical copies) |
| [§3](03-grids.md) | Grids | Creating / renaming / deleting, column and row ratio adjustment and locking |
| [§4](04-placements.md) | Placements | Drag-and-drop placement / moving / swapping, placement-specific properties (Inspector) |
| [§5](05-shared-properties.md) | Shared Properties | Scaling / rotation and flip / cropping / protected regions |
| [§6](06-output.md) | Output | Normal / PhotoBoard, trim mode, preview, PNG export |
| [§7](07-workspaces.md) | Workspaces | Switching between multiple workspaces / import and export |
| [§8](08-history.md) | Operation History | Undo / Redo, bulk jump from the history flyout |
| [§9](09-settings.md) | Settings | Theme / language / default values / auto-save / settings import and export |
| [§10](10-reference.md) | Reference | Keyboard shortcuts / menus / file locations / troubleshooting / glossary |

## Conventions

- **Menu actions**: written in **bold → bold** form, such as "**File → Add Images...**"
- **Button names / UI labels**: shown in bold, such as "**Save**"
- **Keyboard shortcuts**: shown in code font, such as `Ctrl+Z`
- **Code / paths / identifiers**: shown in code font, such as `%LocalAppData%\ViewGrid\`
- **Screen terminology**: for terms such as "grid", "variant", "placement", and "protected region", see the [§10.30 Glossary](10-reference.md)

## Intended Audience

- Those who want a complete overview of ViewGrid's standard workflow
- Those who want to understand the behavior of a specific feature (PhotoBoard / protected regions / workspaces, etc.) in detail
- Those who want to look up keyboard shortcuts or setting values

Some content overlaps with what the Quick Start covers, but this manual explains behavior in greater detail and describes how each feature relates to others.
