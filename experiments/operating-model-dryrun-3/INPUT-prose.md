# 備品・社用品の貸し出し管理ツール 要求メモ

（書いた人: 総務／オフィス運営 担当）

## 背景

今うちの会社、ノートPCの予備機とか、モバイルWi-Fiルーター、プロジェクター、社用スマホ、あと撮影用のカメラ一式とかを、誰が今借りてるのか全然わからなくなってる。Excelの貸出表が共有フォルダにあるんだけど、みんな書き忘れるし、書いても日付がバラバラだし、「あれ、あのルーター誰が持ってったの？」っていう問い合わせが総務に毎週来る。正直もう限界。

特に困ってるのが、出張とか客先常駐で長期間持ち出されるやつ。返却予定日を過ぎても放置されてて、別の人が使いたいときに「貸出中」のまま埋まってる。督促も手作業で、誰に連絡すればいいかもパッと出てこない。

なので、ちゃんと「今どの備品が誰の手元にあって、いつ返ってくる予定か」が一目でわかって、貸し借りの記録が自然に残るツールがほしい。

## やりたいこと

- 借りたい人が、空いてる備品を探して「これ借ります」と予約・貸出申請できる。
- 高価なものや台数が少ないものは、勝手に持ってかれると困るので、総務か上長の承認をはさみたい。安いもの（ケーブルとか変換アダプタとか）はその場でサッと借りられていい。ここの線引きはまだふわっとしてる。
- 返却したら「返しました」を記録。総務側が現物を見て「確かに返ってきた」と確認するステップもほしい気がする（人によっては返したつもりで返ってない、というのが過去にあった）。
- 返却予定日が近づいたら借りてる本人に自動でお知らせ。過ぎたら総務にも通知。
- 備品ごとの履歴（誰がいつ借りていつ返したか）を後から追えるように。何か壊れた・なくなったときに経緯を確認したい。

## 登場する人・役割

- **一般の社員**: 借りる人。基本は自分が借りているもの・これから借りるものが見られればいい。
- **各部署の上長（マネージャー）**: 自分の部下の貸出を承認したり、部下が今何を借りてるか把握したい場面がある。
- **総務／オフィス運営担当（わたしたち）**: 備品そのものの登録・台数管理・最終的な返却確認・督促をやる。全体を見たい。
- **情報システム担当**: PCや社用スマホみたいなIT機器については、貸出のときにキッティング（初期設定）や、誰に渡ったかを別途把握する必要がある。総務とは見たい範囲が少し違う。

役割はだいたいこんな感じだけど、上長と総務の権限の重なり方は、運用してみないと正直わからない部分がある。

## 画面イメージ

1. **備品一覧（借りる人向け）**: いま空いてる／貸出中の備品がカテゴリ別に並ぶ。空いてるものに「借りる」ボタン。貸出中のものは「いつ返却予定か」が見える。誰が借りてるかまで全員に見せるかは迷い中（後述）。

2. **自分の貸出状況**: 自分が今借りているもの、返却予定日、承認待ちの申請。「返しました」を押す画面もここ。

3. **承認・管理画面（上長／総務向け）**: 承認待ちの申請がたまる。承認・却下する。総務はここで返却の現物確認もする。督促が必要な「返却遅れ」リストもここに出したい。

4. **備品の登録・台数管理（総務向け）**: 新しい備品を登録したり、壊れて廃棄したものを「貸出不可」にしたり。ここは総務だけがいじれればいい。

## 守りたいこと

- 高価な備品や数の少ない備品は、承認なしに持ち出されないようにしたい。誰でもポチッと押せると取り合いになる。
- **誰が何を借りているか**は、全部を全員に見せていいのか少し慎重に考えたい。たとえば「○○さんが長期で社用スマホを借りている」みたいな情報は、本人と上長と総務くらいでいい気もする。一方で「このルーターは今ふさがってる」というのは全員見えたほうが便利。**借りている“モノ”の空き状況**と、**借りている“人”が誰か**は、見せる範囲を分けて考えたい。
- 備品の登録や廃棄、台数の変更みたいな大元の操作は、総務以外が触れないようにしたい。間違って消されたりすると困る。
- 過去の貸出履歴は勝手に書き換えられないようにしたい。トラブルのときの記録なので。

## まだ決めきれていないこと

- 承認が必要なものとそうでないものの線引き（金額？台数？カテゴリ？）。ここは総務内でもまだ意見が割れてる。
- 「誰が借りてるか」をどこまで一般社員に見せるか。便利さとプライバシーのバランス。決めきれていない。
- 返却の現物確認を必須にするか、本人の「返しました」だけで完了にしていいか。厳しくすると総務の手間が増える。
- 情報システム担当がIT機器について見たい・やりたいことが、総務と完全には一致しない気がしていて、そこの整理がまだ。
- 部署をまたいで備品を貸すケース（他部署の人が借りる）のときの承認者が誰になるか。
